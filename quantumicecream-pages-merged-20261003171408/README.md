# 每日营养图谱

本项目是一个本地离线优先的个人营养记录 PWA，支持按餐次记录食物、自动计算热量与宏量营养素、自定义食物库、体重历史、BMR/TDEE、趋势图表、自定义背景图片、图片自动配色与可读性保护。

## 启动

最直接的方式是双击项目目录中的 `每日营养图谱.cmd`。它会自动启动本地服务并打开浏览器；使用期间保留命令窗口，关闭该窗口即可退出。

需要 Python 3.10 或更高版本。不要直接双击 `index.html` 使用 Service Worker 功能；也可以在项目目录运行：

```powershell
python serve.py
```

浏览器会自动打开 `http://127.0.0.1:8765/`。如果不想自动打开浏览器：

```powershell
python serve.py --no-open
```

## 数据与隐私

- 所有个人资料、记录、自定义食物、体重和背景都保存在当前浏览器的 IndexedDB 中。
- 网站不连接后端、云服务或第三方接口。
- 可在“个人资料”页导出 JSON 备份；导入会替换当前浏览器中的全部数据。
- 清除浏览器站点数据也会删除应用记录，因此建议定期导出备份。

## 食物营养值说明

内置食物库提供约 130 种常见食物的典型参考值，并区分生、熟和可食部状态。数值允许复制后编辑，但不能替代食品包装标签、实验室检测或医疗建议。

## 测试

在项目目录运行本地服务器后，可访问：

- `tests.html`：计算、数据层、食物库和工具函数测试。
- `tests/ui.integration.test.html`：完整界面流程测试。

测试结果会回传到测试服务器；仓库中的开发测试运行器位于上层 `work/` 目录，不算应用交付文件。
